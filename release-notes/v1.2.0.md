mpv-enjoy 现已集成 mpv-enjoy Home 作为统一入口，可浏览本地媒体目录及 Emby/Jellyfin
服务器，并使用发行包内置的 mpv 独立进程播放。Windows 解压后运行 `mpv-enjoy.exe`，
macOS 打开 `mpv-enjoy.app`；现有 uosc、弹幕、VideoTogether、thumbfast、yt-dlp 和用户
配置方式保持不变。

Windows 仍保留同目录的 `mpv.exe` 供直接调用，并继续使用 `portable_config`。macOS 首页
与播放器位于同一个 App 中，升级时仍不会覆盖已有的 mpv 配置；首页和播放器继续保持进程
隔离，本版本不引入 libmpv。
