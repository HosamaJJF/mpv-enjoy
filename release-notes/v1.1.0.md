# mpv-enjoy 1.1.0

- 加入移植版 VideoTogether 同步观影插件，可通过 uosc 控制栏创建或加入房间。
- uosc 控制栏右侧添加播放/暂停按钮。
- uosc_danmaku 弹幕帧数滤镜默认开启（`vf_fps=yes`，目标帧率
  `fps=60/1.001`）。该滤镜会增加性能开销；如需关闭，请将对应配置文件中的
  设置改为 `vf_fps=no`：

    - Windows：`portable_config/script-opts/uosc_danmaku.conf`
    - macOS：`~/Library/Application Support/mpv-enjoy/config/script-opts/uosc_danmaku.conf`

  macOS 升级安装会保留已有配置；如需使用新默认值，请按需手动修改上述配置文件。
- 弹幕默认字体大小修改为 30（`fontsize=30`）。
